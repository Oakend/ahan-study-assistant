# 阿含经学习助理

阿含经学习助理的配置包、安装说明与版本更新。可用于经文与开示查找、学习讨论、学习整理和共学备课。

## 下载与安装

在 [GitHub Release](https://github.com/Oakend/ahan-study-assistant/releases/tag/v1.0.0) 的 Assets 中下载 `_v1.0.0_.zip`，或从 [Notion 下载与更新页](https://slime-sternum-186.notion.site/41606504867781c3a953e535026a85b1) 下载同一份配置包。

解压后先打开 `使用说明.md`，再根据使用环境选择 Codex 本地配置或 ChatGPT 项目云端配置。完成安装后，在新聊天中核对自己的 Notion 资料入口能否读取。

## 安装助手

- [Windows 10/11 安装助手](https://github.com/Oakend/ahan-study-assistant/releases/download/v1.0.0/AhanStudyAssistant-Windows-v1.0.0.zip)。解压后双击 `Install-AhanStudyAssistant.cmd`。
- [macOS 安装助手](https://github.com/Oakend/ahan-study-assistant/releases/download/v1.0.0/AhanStudyAssistant-macOS-v1.0.0.zip)。解压后双击 `Install-AhanStudyAssistant.command`。

安装助手会下载并校验 v1.0.0 配置包，再在终端引导完成项目配置。
